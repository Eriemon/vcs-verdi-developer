# VCS/Verdi Non-GUI Capability Matrix

This skill covers a scripted non-GUI subset of VCS and Verdi workflows. It does not claim complete coverage of every official Synopsys VCS/Verdi command option or GUI feature. Status values are `supported`, `remote-evidence-required`, `guarded`, and `unsupported`.

| Capability | Status | Evidence Requirement |
| --- | --- | --- |
| Environment probe for `vlogan`, `vhdlan`, `vcs`, `VCS_BIN`, `verdi`, `fsdbreport`, Verdi NPI Python, licenses, PLI, shell compatibility | supported | `check_env.py --json` unit tests and local gate |
| SystemVerilog and Verilog compile planning with include dirs, defines, libraries, multiple filelists, tool overrides, environment injection, expected artifacts, and manifest input | supported | manifest schema tests and `vcs_verdi_check.py --dry-run --json` tests |
| VHDL compile planning with `vhdlan` ordering before `vlogan` | supported | manifest dry-run tests; real execution is `remote-evidence-required` |
| VCS Makefile/filelist import for imported legacy-style projects, including `VCS`, `VERDI`, `VCS_FLAGS`, `SRCS`, `+incdir`, `-top`, VCD dump flags, and `./simv -l` logs | supported | `import_vcs_project.py` unit tests and fixture-based local gate dry-runs built from governed private validation fixtures retained outside the public release payload |
| Course-style Makefile import with `cd <workdir> && vcs`, `$(shell find $(PWD)/../...)`, line-commented `VCS_OPTIONS += ... ###`, explicit `--make-var TOP=...`, `-R`, FSDB `verdi -ssf`, `./<simv> -l`, `urg -dir`, and compile/sim check scripts | supported local plan | `import_vcs_project.py` unit tests and fixture-based local gate dry-runs built from governed course-style project samples; real VCS/URG execution is `remote-evidence-required` |
| Edalize/CAPI2-style VCS input import for files, file types, toplevel, plusargs, vlogdefines, vlogparams, `vcs_options`, and `run_options` | supported | `import_edalize_project` unit tests based on governed Edalize-compatible JSON fixtures |
| cocotb VCS/VPI non-GUI dry-run planning for Verilog/SystemVerilog examples, including `pli.tab`, `+vpi`, `-P`, `+define+COCOTB_SIM=1`, `-load`, `MODULE`, `TOPLEVEL`, and `TOPLEVEL_LANG` | supported local plan | `cocotb_vcs_flow.py` unit tests and fixture-based local gate dry-runs built from governed cocotb sample projects; real cocotb/VCS execution is `remote-evidence-required` |
| cocotb VCS VHDL/VHPI execution | unsupported | The cocotb VCS reference path is VPI-only; `cocotb_vcs_flow.py` must return `vcs_cocotb_vhdl_unsupported` when `VHDL_SOURCES` are present |
| PicoRV32/RISCV-DV style VCS filelist import with `cd <dv> && vcs -f cfg/vcs.f`, `+define+`, `-sverilog`, `-cm`, `-cm_dir`, `-timescale`, and explicit `simv` output | supported | `import_vcs_project.py` unit tests and fixture-based local gate dry-run against the governed PicoRV32/RISCV-DV sample; real VCS execution is `remote-evidence-required` |
| RISCV-DV generator, VCS compile, `simv +hex/+trace`, URG, and trace-compare command planning | supported | `riscv_dv_flow.py --dry-run --json` tests; RISCV-DV, RISC-V GCC, Spike, VCS, and URG execution remain `remote-evidence-required` |
| ModelSim Tcl and Icarus Makefile conversion into VCS manifest candidates with source glob diagnostics, `SIMULATION` defines, include dirs, top module, and pre-sim hex artifact checks | supported | `import_vcs_project.py` tests and fixture-based local gate dry-runs against the governed ModelSim/Icarus conversion sample; missing RTL, hex, or cross toolchain inputs are blockers, not pass evidence |
| KVIPS APB/AHB/AXI4 VCS planning with `-ntb_opts uvm-1.2`, filelist expansion, UVM plusargs, regression lists, FSDB PLI, `fsdbreport`, and guarded `verdi -ssf -nologo -exit` checks | guarded | `kvips_vcs_flow.py` tests and fixture-based local gate dry-runs against the governed KVIPS-style sample; UVM, VCS, and Verdi execution are optional external dependencies and not core low-dependency support |

| AISS-style VCS/VPD target planning with guarded incomplete gate-level netlist targets | supported local plan | `aiss_vcs_flow.py` tests and fixture-based local gate dry-runs against the governed AISS-style sample; real VCS/VPD execution is `remote-evidence-required` |

| URG runtime and loader diagnostics | supported | `urg_runtime_probe.py` tests; remote evidence must include wrapper, `vcs -location`, `ldd`, candidate hashes, loader activation order, and optional strace evidence when coverage fails |
| URG coverage variant matrix for wrapper/direct `urg1` and line/cond/tgl/combined reports | supported | `urg_coverage_matrix.py` unit tests; real execution remains `remote-evidence-required` |

| UCAPI overlay patch workaround for URG internal failures | guarded | `patch_ucapi_overlay.py` unit tests; 2026-05-16 scan-only remote EDA evidence reported `no_match` for the CSDN byte pattern on W-2024.09-SP1; apply only inside validation overlays with explicit `VCS_VERDI_ALLOW_UCAPI_PATCH=1`, and require runtime probe evidence that patched libraries are loader-effective; never patch `/tools/synopsys` |

| Claim/evidence hard gate for factual readiness statements | supported | `evidence_claim_gate.py` unit tests and local quality gate against `assets/evidence/non_gui_claims.json`; factual claims without evidence fail |

| Verdi RC layout generation for signal restore scenarios | supported | `generate_rc.py` fixtures and review checklist |
| GUI Verdi automation, Tk send, and IPython-driven control | guarded | Not part of the non-GUI confidence target |
| Complete coverage of every official Synopsys option | unsupported | Explicitly out of scope |

Supported rows must have at least one local unit test, dry-run test, or remote execution record. Rows marked `remote-evidence-required` must not be reported as factually executed from a Windows-only local run. Dry-run output, GUI launch, or compile-only success never upgrades `delivery_execution_confidence` or `truth_execution_confidence` to `passed`. `delivery_execution_confidence` covers the verified non-GUI mainline; `truth_execution_confidence` additionally requires URG report generation to pass.
